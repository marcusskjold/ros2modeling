To use this package, install all dependencies as defined in pyproject.toml
To use the graph drawing features, a recent version of graphviz must also be properly installed.
Finally, to perform any model checking, UPPAAL 5.0 should be installed and licensed, and the `verifyta` executable contained inside the distribution should be accessible to our program.
`verifyta` is how we run UPPAAL queries automatically without launching the UPPAAL GUI.
We have provided the module roserer.verifyta_resolver to help the resolve the path to `verifyta`.
If using a mac or a windows with WSL, this may resolve verifyta without further issue.
Otherwise, you must find the `verifyta` executable manually, and then either make a symlink into the cwd, or you should provide a .env in the cwd with VERIFYTA_PATH="path/to/verifyta".

The package was developed, used and tested with the Python package manager uv 
https://docs.astral.sh/uv/

Our tests were run and coverage report generated by calling:
uv run pytest --cov=roserer

To replicate the first example from the Evaluation section, we run
uv run demo/evaluation_demo
